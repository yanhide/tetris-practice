# シンプル テトリス

ブラウザだけで遊べる、初心者向けのシンプルな1人用テトリスです。
HTML / CSS / JavaScript の役割が分かりやすいように、次の3ファイルに分けています。

- `index.html`: 画面の部品（タイトル、ゲーム画面、操作説明）を作ります。
- `style.css`: 画面の見た目（色、余白、レイアウト）を整えます。
- `script.js`: テトリスの動き（移動、回転、落下、ライン消去、ゲームオーバー）を担当します。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「ゲーム開始 / リスタート」ボタン、または `Enter` キーでゲームを始めます。
3. 落ちてくるブロックを操作して、横一列をそろえます。
4. 横一列がすべて埋まると、そのラインが消えてスコアが増えます。
5. ブロックが上まで積み上がり、新しいブロックを置けなくなるとゲームオーバーです。

## 操作方法

| キー | 動き |
| --- | --- |
| `←` | 左に移動 |
| `→` | 右に移動 |
| `↑` | 回転 |
| `↓` | 1マス下に移動 |
| `Enter` | ゲーム開始 / リスタート |

## 初心者向けの読み方

### 1. `index.html` を見る

`canvas` というタグがゲーム画面です。JavaScript がこの `canvas` にブロックを描きます。

### 2. `style.css` を見る

背景色、文字色、ゲーム画面の枠、ボタンの見た目などを設定しています。
`@media` の部分は、画面が狭いときに縦並びへ切り替えるための設定です。

### 3. `script.js` を見る

主に次の流れで動きます。

1. 20行 × 10列の空の盤面を作る。
2. ランダムなブロックを1つ作る。
3. 一定時間ごとにブロックを下へ動かす。
4. 壁、床、固定済みブロックに当たったらブロックを盤面に固定する。
5. 横一列がそろっているか調べ、そろっていれば消す。
6. 次のブロックを作る。
7. 次のブロックを置けなければゲームオーバーにする。

コード内にもコメントを多めに入れているので、関数ごとに少しずつ読んでみてください。
