# シンプル テトリス

## ゲーム概要

ブラウザでそのまま遊べる、HTML / CSS / JavaScript だけで作ったシンプルな1人用テトリスです。
外部ライブラリは使っていません。

落ちてくるブロックを左右に動かしたり回転させたりして、横一列をそろえるとラインが消えます。
ラインを消すとスコアが増え、ブロックが上まで積み上がるとゲームオーバーになります。

## 操作方法

| キー / ボタン | 動き |
| --- | --- |
| `←` | ブロックを左に移動 |
| `→` | ブロックを右に移動 |
| `↓` | ブロックを早く落とす |
| `Space` | ブロックを回転 |
| 「ゲーム開始 / リスタート」ボタン | 最初からゲームを始める |

## ファイル構成

```text
.
├── index.html   # 画面の部品を作るファイル
├── style.css    # 見た目を整えるファイル
├── script.js    # テトリスの動きを作るファイル
└── README.md    # この説明ファイル
```

## ブラウザでの起動方法

1. このフォルダを開きます。
2. `index.html` をダブルクリックしてブラウザで開きます。
3. 「ゲーム開始 / リスタート」ボタンを押すとゲームが始まります。

サーバーやビルドツールは不要です。
