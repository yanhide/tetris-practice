# シンプル テトリス

ブラウザだけで遊べる、初心者向けのシンプルな1人用テトリスです。
HTML / CSS / JavaScript の役割が分かりやすいように、次の3ファイルに分けています。

- `index.html`: 画面の部品（タイトル、ゲーム画面、次ブロック表示、操作説明）を作ります。
- `style.css`: 画面の見た目（色、余白、レイアウト、エフェクト）を整えます。
- `script.js`: テトリスの動き（移動、回転、落下、ライン消去、ゲームオーバー、追加機能）を担当します。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「ゲーム開始」ボタン、または `Enter` キーでゲームを始めます。
3. 落ちてくるブロックを操作して、横一列をそろえます。
4. 横一列がすべて埋まると、そのラインが消えてスコアが増えます。
5. ブロックが上まで積み上がり、新しいブロックを置けなくなるとゲームオーバーです。

## 操作方法

| キー | 動き |
| --- | --- |
| `←` | 左に移動 |
| `→` | 右に移動 |
| `↑` | 回転 |
| `Space` | 回転 |
| `↓` | 1マス下に移動 |
| `Enter` | ゲーム開始 / 一時停止 / 再開 / ゲームオーバー後の再挑戦 |

## 追加した機能

### 次のブロック表示

ゲーム画面の横に「次のブロック」を表示します。
次に何が来るか分かるので、置き場所を考えやすくなります。

### 一時停止

プレイ中に `Enter` キー、または画面下のボタンを押すと一時停止できます。
もう一度押すと再開します。

### Spaceキー回転

`↑` キーだけでなく、`Space` キーでもブロックを回転できます。

### 4ライン消し演出

一気に4ラインを消すと、盤面が光り、特別メッセージが表示されます。
通常のライン消去点に加えて、ボーナス点も入ります。

### お邪魔ブロック

一定時間ごとに、下から穴あきのお邪魔ブロックがせり上がります。
画面横の「お邪魔」欄に、次にせり上がるまでの秒数を表示します。

### アイテム機能

ときどき、1マスのアイテムブロックが落ちてきます。
アイテムは着地するとすぐ発動します。

| 表示 | 名前 | 効果 |
| --- | --- | --- |
| `B` | 爆弾 | 着地した場所の周囲3×3マスを消します。 |
| `L` | 1列消去 | 着地した横一列を消します。 |
| `T` | 時間停止 | 一定時間、お邪魔ブロックのせり上がりを止めます。 |

## 初心者向けの読み方

### 1. `index.html` を見る

`canvas` というタグがゲーム画面です。
メインのゲーム画面用 `canvas` と、次のブロック表示用 `canvas` の2つがあります。

### 2. `style.css` を見る

背景色、文字色、ゲーム画面の枠、ボタンの見た目などを設定しています。
`@keyframes` の部分は、4ライン消しなどのエフェクトを動かすための設定です。
`@media` の部分は、画面が狭いときに縦並びへ切り替えるための設定です。

### 3. `script.js` を見る

主に次の流れで動きます。

1. 20行 × 10列の空の盤面を作る。
2. 現在のブロックと次のブロックを作る。
3. 一定時間ごとにブロックを下へ動かす。
4. 壁、床、固定済みブロックに当たったらブロックを盤面に固定する。
5. 横一列がそろっているか調べ、そろっていれば消す。
6. アイテムなら、爆弾・1列消去・時間停止の効果を発動する。
7. 一定時間ごとにお邪魔ブロックを下から追加する。
8. 次のブロックを現在のブロックにする。
9. 次のブロックを置けなければゲームオーバーにする。

コード内にもコメントを多めに入れているので、関数ごとに少しずつ読んでみてください。

## 改造アイデア

- レベルアップで落下速度を速くする

- アイテムの種類を増やす
- お邪魔ブロックの間隔をスコアに応じて短くする
